# BILFO Cleaner

Descargas de BILFO Cleaner, la herramienta gratuita de BILFO para limpiar y optimizar tu Mac.

- **Primera instalación:** descarga el `.dmg` de la [última versión](https://github.com/alanrodg/bilfo-cleaner-releases/releases/latest), ábrelo y arrastra la app a Aplicaciones.
- **Actualizaciones:** la app avisa sola cuando hay una versión nueva (menú BILFO Cleaner → Buscar actualizaciones…).

Este repositorio solo contiene las versiones publicadas. Las tareas de limpieza las ejecuta [Mole](https://github.com/tw93/mole) (GPL-3.0), incluido dentro de la app.
